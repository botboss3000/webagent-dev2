01 / Conversational agents

Chat with agents that actually do the work

Every message can call real tools — search, browse, schedule, remember. Multi-step turns stream live, and a run keeps going even if you close the tab.

  • Ask · Plan · Auto modes — you decide how much it runs on its own
  • Watch each tool call as it happens, with full inputs and results
  • Markdown answers, attachments, voice input and read-aloud

02 / Gen UI workspace

Describe a dashboard. Watch it appear.

Type what you want in the Gen UI and the agent renders a live, interactive page beside your chat — then keeps refining it as you talk.

  • Multiple named genui, each with its own focus
  • Buttons and forms inside a genui trigger real agent work
  • Secure logins flow straight into an encrypted vault
Gen UI workspace
03 / Browser control

Hand the web to your agent

A real, persistent browser tab lives beside chat. Share it and the agent can see the page you're on, click through sites, and act as your logged-in self.

  • Logins survive restarts; tracker cookies are blocked
  • Drive it headless, or watch a live mirror of your own Chrome
  • Credentialed logins the agent never actually sees
In-app browser
04 / Shared Wiki

One knowledge base, for everyone

A company-wide encyclopedia your whole team — and every agent — can read, search and edit. Hybrid semantic + keyword search finds the right page fast.

  • Markdown articles with [[wiki-links]] and backlinks
  • Full revision history — view and restore any version
  • Draft vs published — public visitors only see what you choose
Shared Wiki
05 / Automations

Set it once. It runs itself.

Schedule tasks, react to events, and deliver results wherever you want — a chat, a fresh session, a channel or a webhook. With guardrails built in.

  • Time schedules, one-shot reminders and event triggers
  • Run as this agent, or spin up a dedicated clone
  • Every run logged to a dashboard with limits and retries
