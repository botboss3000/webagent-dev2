PRODUCT TOUR

One workspace for agents that can act.

WebAgent brings conversation, tools, live interfaces, knowledge and automation into one system you control.

01 / Conversational agents

Chat with agents that actually do the work

Agents can search, browse, work with files and complete multi-step tasks while every tool call remains visible.

02 / GenUI workspace

Describe a dashboard. Watch it appear.

Create live, interactive pages beside the conversation, then refine them naturally as the work evolves.

03 / Browser control

Hand the web to your agent

Share a persistent browser so an agent can see pages, navigate sites and help inside authenticated workflows.

04 / Shared knowledge

One knowledge base for people and agents

Build a searchable wiki with revisions, backlinks and publishing controls that every approved agent can use.

05 / Automations

Set it once. It runs itself.

Schedule tasks, react to events and deliver results to chats, fresh sessions, channels or webhooks.
