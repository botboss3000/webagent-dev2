# Compact toggle-list — per-area conformance audit

Reference companion to the **`ui_toggle_list`** skill (Codebase Admin ability). The skill
carries the *pattern and its contracts*; this file carries the *inventory*: every admin
surface that uses (or should use) the shared `.ac-list` / `.ac-row` / `.ac-ability-*`
component, with the exact files, classes and current state for each.

Check **all** of these when the toggle-list design changes, so the change lands on every
conformant surface at once.

### Every area that uses (or should use) this pattern

When the toggle-list design changes, check **all** of these so the change lands everywhere at once.

- ✅ **Conformant** = on the shared `.ac-list` / `.ac-row` / `.ac-ability-*` component.
- ⏸️ **Left as-is (by decision)** = not converted on purpose — either it's not a list, or the owner chose to leave it.
- ❌ **Divergent** = still a bespoke look that *should* be migrated.
