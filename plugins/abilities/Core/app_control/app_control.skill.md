# App Control

Two-way control of what you're looking at. The agent can switch the main view (Browser, Pages, Agents...), show or hide the chat panel, and resize it — and you can right-click anywhere in the app to point at something and send it to the chat (a small panel with one-click questions plus a message box, sharing the element you clicked and where on the page it is). On by default; switch off to remove both halves platform-wide.

Each tool has its own personal skill under `tools/`, delivered when that tool becomes callable.
