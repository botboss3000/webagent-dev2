Setting up your admin account…
This page appears only on a brand-new install, until the first admin is created — after that it closes for good and everyone goes to the sign-in screen. Whoever reaches it first sets the admin password, so on a public server open it and complete setup right away. To skip this page entirely, pre-set the password at deploy time (the Deploy panel’s “set the password now” option, or the BOOTSTRAP_ADMIN_PASSWORD environment variable) and the admin is created automatically on first boot.
