# V3 Workspace
This ability prepares an isolated source snapshot in the current session only.
v3_workspace_status reports whether webagent-v3 is seeded and returns its complete
review digest. v3_workspace_action accepts seed, review, read or patch. A read
path is relative to webagent-v3; patch requires expected_review_sha256.
Never target the live checkout, other sessions or encrypted application data.
Frozen proposals and durable receipts belong to authenticated Rust administration,
not files written by this adapter. Verify the exact review before proposing.
Fixed Cargo jobs are check, test and release with --locked, no arbitrary flags.
They capture all source inputs before and after execution; raced results are stale.
Cargo caches and targets remain inside this session source sandbox. A release job
builds a binary only; it never deploys. Readiness remains pending API acceptance.
